You now know what ZIO Blocks is, how its blocks are designed, and the four blocks most applications start with. The rest of the documentation has four kinds of pages, each for a different moment.

## How the Documentation Is Organized

Each kind of page answers a different question:

| Kind of page                                  | Read it when you want to...                          |
| --------------------------------------------- | ---------------------------------------------------- |
| [Tutorials](/guides/tutorials)                | Learn a block step by step, from nothing             |
| [How-to guides](/guides/how-to)               | Solve one specific task in a project                 |
| [Migration guides](/guides/migration)         | Move existing code from another Scala library        |
| [Reference](../reference/index.md)            | Look up every type and method of a block             |

The tutorials are the natural next step. Each one builds a small program from scratch, and they are listed here by what you want to do:

| You want to...                                 | Start with                                                                                                           |

If something is unclear or does not work as described, ask on the [ZIO Discord](https://discord.gg/2ccFBr4) or open an issue in the [GitHub repository](https://github.com/zio/zio-blocks). The [API documentation](pathname:///api/) lists every public type of every block.
