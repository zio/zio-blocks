# Reference page design (2026-11-03)

Design source for the zioblocks.com Reference landing page. Published as a Design artifact: https://claude.ai/artifact/KbvtWuh3iUqJfa37G68UHw (private).

- `project/canvas.json`: canvas index (frames, titles).
- `project/Main.dc.html`: design A, dense directory (light). `A-Dark`, `A-Phone` import it.
- `project/B-Cards.dc.html`: design B, group cards with a Start here row (light). `B-Dark`, `B-Phone` import it.

Block data (names, artifacts, platforms, descriptions) is copied from `docs/index.md` and `docs/sidebars.js`; an implementation should generate it instead of copying.
