## 1. Method and sources

**Library state.** Since `v0.0.56` (2026-10-05) every commit under `*/src/main` is Scaladoc or a doc fix, apart from #1743 (Scala 3.9/3.10 split) and #1826 (drop `-experimental`). The only code change is in `endpoint`: the `PathCodec`/`SegmentCodec` constructors moved into platform-specific traits with unchanged signatures (`git diff --stat v0.0.56 -- endpoint`: 6 files). So the API on `main` is, for guide purposes, the published 0.0.56 API, and no candidate below loses an F point for "unreleased API". F = 2 below means user glue, a third-party dependency, or a known-bug workaround; Scala-3-only sql items keep F = 3, as backlog H-18 to H-20 do. v0.0.57 is a draft release; 18 example builds pin 0.0.56 (X-11 still holds).

**Five research passes** (2026-10-29), each recorded in full in the session scratchpad:

1. **Coverage map** (repo only): every published module mapped to the guides that teach it (imports plus `mdoc:embed` example files, then checked by hand), its reference pages, untaught public API with `file:line`, and a re-check of every §7 blocker on `main`.
